## 3. Intentional non-issues (checked, deliberately not flagged)

- **Report → Insight coupling**: `Schemata.Report.Foundation` references `Schemata.Insight.Foundation` and `Report.Skeleton` references `Insight.Skeleton`; this is the design-stage exception explicitly allowed by the brief/AGENTS. The reverse edge does not exist.
- **Tenancy logic in scheduling/actor/flow**: `grep ITenant` over the whole execution scope is empty at HEAD; no component ships a default `ITenant`, and per-tenant isolation is repository/DI-owned (the #350 direction). `TenantJobExecutionAdapter`/`TenantSchedulingExtensions` are gone.
- **Two flow engines (`Bpmn` / `StateMachine`)**: both are `IFlowRuntime` provider implementations selected through keyed service resolution (`CallActivityExecutor.cs:96-100` `GetKeyedService<IFlowRuntime<…>>(registration.Engine)`); this is the allowed provider pattern, not a duplicated engine path.
- **`InMemoryInsightSourceCatalog` + `DatabaseInsightSourceCatalog` / `OrderCompiler` package / push transport providers**: provider packages registered enumerable/keyed through DI; allowed by AGENTS’ package taxonomy.
- **`IActorRouting` receives an `IServiceProvider`**: it is used by Report routing to resolve `IReportDefinitionStore`; DI-resolved optional/routing dependency, not a static carrier.
- **`InsightQueryState`** (`Insight.Http/Linking/InsightQueryState.cs`): a static class holding only a `static readonly object` key; the per-request value lives in `HttpContext.Items`. This is ASP.NET request state, not a static state carrier, so it does not violate principle 12.
- **`LinkValue.Serialize` de-duplicating links and `LinkHeaderResultFilter`/`GrpcLinkMetadataInterceptor` swallowing `ArgumentException`**: explicit, documented “links are ancillary metadata” policy; does not fail a successful response. (Noted as a trade-off, not flagged.)
- **`CompensationCoordinator.InvokeAllAsync` notifying observers once per handler**: BPMN compensation invocations are individually observable; not a defect on inspection.
- **Custom job/actor/flow entity-type registration (#350)**: data-reviewer’s assignment; this review only confirms no `ITenant` implementations remain in the execution scope.
- **`Schemata.Messaging.RabbitMq` static `IsStream` field**: per-type (compile-time) metadata, not per-request state.
- **The standalone `Schemata.Expressions.Order` package**: single stateless `IOrderCompiler` provider, pluggable via DI; justified by the provider-package convention.
