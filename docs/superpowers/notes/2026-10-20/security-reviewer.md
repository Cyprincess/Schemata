## 4. Top-10 (act in this order)

1. **R-SEC-01** — pure implicit `id_token`/`id_token token` responses omit the ID token (`IsUserGrant` missing `GrantTypes.Implicit`). One-line fix + test; currently breaks the flow #107 claims to deliver.
2. **R-SEC-02** — SCIM `active` overloads Identity lockout and deprovisioned users can still refresh/rotate tokens; introduce one administrative-active admission owner and consult it from `ISubjectProvider`.
3. **R-SEC-03** — the validated effective `response_mode` is discarded after the authorize leg; interactive success delivery re-infers it, so a form_post-only host gets `query` callbacks (#351 residual).
4. **R-SEC-05** — SCIM PATCH/filter/externalId are absent, so the #123-125 acceptance ("SCIM provisioning") cannot be claimed; PATCH is the single biggest missing protocol owner.
5. **R-SEC-04** — delete the duplicated auto-approve vs interactive sign-in preparation (root cause of R-SEC-03); one approval owner.
