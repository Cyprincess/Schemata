## 3. Intentional non-issues (checked, deliberately not flagged)

- **`Relax*` authorization switches** — allowed framework-user downgrade options per the brief; not reviewed as capability flags.
- **`TenantContext` static `AsyncLocal`** (`src/Schemata.Tenancy.Skeleton/Tenancy/TenantContext.cs:8-30`) — the scoped-restoration execution-identity design settled by earlier remediation (#18); scoped leases restore the parent frame, and `grep -rn "TenantContext" src --include='*.cs' | grep -v Tenancy` is empty, so no tenant state leaks into other components. Not flagged.
- **Synchronous `MemoryCacheTenantProviderCache.Dispose()` blocking on `IAsyncDisposable` providers** (`MemoryCacheTenantProviderCache.cs:434-440`) — documented as host-shutdown/scope-teardown only; the request/acquisition path is async now (#337). Keep as documented trade-off.
- **`SessionCache` sync members throwing `NotSupportedException` on async backends** (`SessionCache.cs:73-78`) — explicitly documented policy; it removes the blocking path rather than hiding it. Not flagged.
- **`ISynchronousCacheBackend` presence-not-support-probe contract** (`Caching.Skeleton/ISynchronousCacheBackend.cs:7-19`) — deliberate design note; tenancy binds its own rejecting wrapper, and the capability is not used as a support probe. Not flagged.
- **`ITenant` trait living in `Schemata.Abstractions`** — allowed by the clarified contract (other components may read the trait; no tenant logic leaks — grep above is empty).
- **`Resource.Foundation` → `Security.Skeleton` compile dependency for access advisors** — `IAccessProvider`/`IPermissionResolver` are Security **Skeleton** contracts, so this is legitimate; only the *Security.Foundation* reference is flagged as a stale-dependency candidate (RD-10a), not as a component-isolation violation (the shared `ResourceSecurityRegistration` seam is in Core/Security.Skeleton, and authorization-wrap registration is opt-in via `WithAuthorization()`).
- **Report → Insight coupling** — the explicit design-stage exception recorded in the brief/AGENTS.
- **`LinkValue.Serialize` de-duplicating identical link-values and `LinkHeaderResultFilter` swallowing `ArgumentException`** — documented "links are ancillary response metadata" policy; a malformed contributed target may not fail a successful response. Not flagged.
- **`DefaultResourceTypeResolver` ambiguity exceptions at construction** (`Resource.Foundation/DefaultResourceTypeResolver.cs`) — single authoritative index, fails fast on duplicate canonical patterns; a policy choice, not over-defense.
- **`ResourceRegistration` copy constructor / `IReadOnlyList<Operations>? Operations == null` sentinel** — data-only registration model (null = all operations); documented semantics, not a capability flag.
- **`MemoryCacheBackend`/`RedisCacheBackend` provider duplication** — allowed provider-adapter pattern over one `ICacheBackend` contract; both are exercised against the shared `CacheProvider`/key-normalizer layer and implement the documented CAS/refresh semantics.
- **`AdviceValidateResourceReferenceExistence.ExistsDelegates` reflection cache** — bounded per target type, metadata only (no scoped services captured); acceptable analogue of the advisor metadata pattern.
- **`Tenancy.Caching` per-tenant outlet declarations (`UseShared`/`UseDedicated`)** — deliberate architecture with duplicate/conflicting declaration rejection; the *automatic wrapping* gap is RD-02, not the outlet model itself.
- **`InsightQueryState`** — static class holds only a `static readonly object` key; the per-request token lives in `HttpContext.Items` (ASP.NET request state, not a static carrier). Same conclusion as execution-reviewer.
- **`IdentityOperationHandler` / custom-method execution carrier = inner request DTO** — the idempotency execution rides the DTO the handler already receives (`ResourceMethodOperationHandler.cs:132`); explicit payload, not wrap-style data passing.
- **`Schemata.Scheduling` finalization no longer dispatching an internal `IRequestDispatcher` request** — fixed; residual schedule-loss is #345/REX-03 and is recorded in the verdict, not re-reported as a new finding here.
